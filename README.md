# Fullstack · Des événements de paiement vérifiables — élève

**4 h 30 · Java / React / Événements · PilotCrew.** Recevoir des événements signés par un mock local, gérer leur rejeu et afficher un état serveur sans régression.

Le protocole de signature est inventé et public pour le cours. Il permet des tests locaux ; il n’est l’implémentation d’aucun prestataire de paiement.

Ce support contient les tutoriels, mémos et espaces de réponse. Créer le code demandé dans `backend/` et `frontend/` ; le corrigé est privé et séparé. Les six séances forment un fil rouge progressif de **27 heures**, sans promesse de niveau senior.

## Préparer la séance

Avant cette séance, importer votre réalisation validée de `java-react-03-checkout-eleve` dans votre nouvelle copie `java-react-04-webhooks-eleve`. Reprendre backend/, frontend/ et scripts/ lorsqu’ils existent, ainsi que leurs configurations et lockfiles. Exclure .git/, target/, node_modules/, dist/, caches et sorties privées. Garder les documents de ce nouvel atelier. Noter le commit de provenance et exécuter les contrôles disponibles avant le début des 270 minutes.
